# The Question Library

*A slowly-gathered collection of questions worth sitting with — the Muse's instrument.*

These are not generated. They are **found** — in books, conversations, therapy, podcasts,
journals, and the unexpected moments that make you stop. A great question is rare. This
library grows whenever we encounter one that genuinely earns its place, never by filling
quotas. A small set of exceptional questions is worth more than a large set of plausible ones.

**Voice test for inclusion:** a question belongs here only if it is unmistakably *a reader's*
question — something no one would type in casual chat. It should open a door, never imply an
answer. If it could be confused for the user's own words, or if it reaches toward a conclusion,
it isn't a Muse question.

The Muse *offers* these. It never insists. The author always keeps the pen.
